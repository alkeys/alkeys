## 🏛️ Arquitectura y buenas prácticas

Me interesa construir software aplicando principios y patrones que faciliten su mantenimiento y evolución.

- **Clean Architecture:** separación de responsabilidades y reglas de negocio.
- **Hexagonal Architecture:** Ports & Adapters para desacoplar el dominio.
- **SOLID:** diseño orientado a objetos mantenible.
- **REST API Design:** diseño de servicios y contratos HTTP.
- **DTO Pattern:** transferencia estructurada de información.
- **Database Design:** modelado relacional y consultas geoespaciales.
